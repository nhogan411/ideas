# Work LLM Wiki

A proposal for a team knowledge wiki at work — an LLM-maintained, self-serve knowledge base that synthesizes knowledge currently scattered across READMEs, AGENTS.md files, Storybook stories, Figma specs, GraphQL schemas, and individual team members' heads, and keeps it current automatically as systems change. Directly inspired by [`idea-fuel`](../idea-fuel/)'s Karpathy/Platformer article.
