# Timeline App

A structured, collaborative, embeddable timeline tool for capturing and sharing chronological histories — medical history for doctors/specialists, home project history, trip history, vehicle history, or a journalist's chronological investigation record. A SaaS, API-first web app (not a package, not a native mobile app).
