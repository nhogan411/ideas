# Ideas

A collection of project briefs, design specs, and working notes for personal projects in various stages of thought — from early brainstorming to near-ready-to-build specs. Nothing in here is necessarily committed to; this is a scratchpad for developing ideas before (or instead of) turning them into real repos.

## Directory Overview

| Directory | What It Is |
|---|---|
| [`civic-engagement/`](civic-engagement/) | **Civic Pulse STL** — an app concept to make local St. Louis-area government activity (agendas, zoning, board decisions) legible and personally relevant to residents. Brief, data models, positioning, and design notes. |
| [`idea-fuel/`](idea-fuel/) | Source material / inspiration that fuels other ideas in this repo (e.g., articles that sparked a concept). Not a project of its own. |
| [`policy-graph/`](policy-graph/) | **Policy Knowledge Platform** — a queryable knowledge base of policy problems/solutions that generates legislative proposals as an output, conceived as a left-of-center answer to "Project 2025." |
| [`raw/`](raw/) | Raw scraped/clipped source material (currently recipes pulled from various food blogs via Obsidian Web Clipper, one subdirectory per source site) that feeds the `recipe-wiki` project. Unprocessed input, not a project spec. |
| [`recipe-wiki/`](recipe-wiki/) | A local-first, AI-queryable personal culinary knowledge base ("Karpathy-style LLM wiki" for cooking) — turns raw recipe clippings into a structured, queryable Markdown knowledge base. |
| [`restaurant-app/`](restaurant-app/) | A Letterboxd-style restaurant discovery/logging app for finding and tracking great local restaurants through a trusted social graph, starting in St. Louis. |
| [`scraper/`](scraper/) | Design spec for a general-purpose HTML-to-Markdown batch scraper — a scriptable replacement for the Obsidian Web Clipper, feeding `raw/` and downstream wiki projects. |
| [`timeline-app/`](timeline-app/) | Design spec for a SaaS, API-first collaborative timeline tool for recording and sharing chronological histories (medical history, home projects, investigations, etc.). |
| [`work-llm-wiki/`](work-llm-wiki/) | Proposal for a team knowledge wiki at work — an LLM-maintained, self-serve knowledge base synthesizing scattered docs/READMEs/Figma specs/tribal knowledge into one living source of truth. |

## Conventions

- Each project directory contains one or more Markdown docs (briefs, design specs, data models) describing the idea — there is no code here, just planning artifacts.
- Docs marked `Status: WIP / Draft` reflect early brainstorming, not committed designs.
